HTML

Estructura

Todo documento HTML tiene la siguiente estructura

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Receta de pan amasado</title>
  <meta name="description" content="Cómo hacer pan amasado">
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- Aquí va todo lo visible -->
  <script src="app.js" defer></script>
</body>
</html>

Ninguna línea está de adorno, todas significan algo

  1. <!DOCTYPE html>: Activa el standards mode. Si lo omites, el navegador entra en quirks mode. quirks mode solo existe por el concepto de compatibilidad hacia atrás, es altamente recomendado programar en HTML estándar.

  2. html lang="es": Le dice al lector de pantalla con qué pronunciación leer, y al navegador cuándo ofrecer traducción.

  3. meta charset="UTF-8": Utiliza la codificación UTF-8 en la escritura. Sin esta línea, las tildes y la ñ pueden aparecer como Ã±.

  4. meta name="viewport"...: Sin esta línea, un móvil dibuja la página como si midiera ~980px de ancho y la achica entera. El texto queda diminuto y ninguna media query funciona como esperas.

  5. <title>: Es el texto de la pestaña, del historial y del título azul en los buscadores

  6. <head> vs <body>: En head va información acerca de la página, que no se ve. En body va lo que se ve.

  7. defer: El script se descarga en paralelo y se ejecuta cuando el HTML ya está listo.

Sintaxis

Tipos de texto

<h1> a <h6> sirven para definir una jerarquía, como el índice de un libro. No los eliges por el tamaño de letra (eso lo controla CSS), si no por su orden lógico. Usa un solo <h1> por página y no saltes niveles.

Párrafos

<p> es un párrafo. Sirve solo para saltos de línea con significado dentro de un mismo parrafo, como para separar líneas de una dirección o un poema. Nunca lo uses para dar espacio, eso es trabajo de CSS.

Estilos de letra

<strong> vs <b>: strong significa importante y el lector de pantalla lo enfatiza. <b> solo cambia el estilo. Lo mismo pasa con <em> (énfasis) y <i> (estilo).

Bloque vs inline

  • Los elementos de bloque ocupan toda la línea y empiezan en una nueva (Ej: <h1>, <p>, <div>, <section>).

  • Los elementos inline viven dentro de los de bloque (Ej: <strong>, <em>, <a>, <span>).

Regla de anidamiento: un <p> no puede contener elementos de bloque. Si escribes <p><div>...</div></p>, el navegador cierra el <p> por su cuenta y tu estructura se rompe sin avisarte.

JavaScript

JavaScript tiene 7 tipos de datos primitivos, todo lo demás es un objeto

  • string
  • number
  • bigint
  • boolean
  • undefined
  • null
  • symbol

Para JS, hay varias trampas respecto a los tipos de datos

valor typeof(valor) Nota
NaN number "Not a Number" es de tipo number
undefined undefined
null object bug de 1995 que nunca se corrigió
[] object útil: Array.isArray([])
function(){} function function no es dato primitivo

Estos bugs se deben a que el motor inicial de JS fue hecho en solo 10 días, sin tiempo de revisar.
